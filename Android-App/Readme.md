# Android-App Combination-Projekt (Vue & Firebase)
Status: In Construction 🚧

Dies ist eine Android App für die hilfe zur Kombination von Kleidung, gebaut mit **Vue und Dart**. Es bietet eine App-Oberfläche mit verschiedenen interaktiven Modulen.

## Features & Modules

### Authentifizierung (Firebase)
Der Zugang zur App ist durch **Firebase Auth** geschützt. 
* Nur autorisierte und registrierte Nutzer können sich in die App einloggen.
* Login erfolgt sicher über E-Mail und Passwort.
* Die Session-Verwaltung wird komplett von Firebase übernommen.

![Alternativtext: Login Seite](./screenies/Login.png)


### Kamera Funktion
Mit der Kammera lassen sich Fotos von neuer Kleidung aufnehmen.
* Die Fotos werden in einer Datenbank gespeichert auf die man per App zugreifen kann.
* Optimiert für verschiedene Bildschirmgrößen.

![Alternativtext: In App Kamera](./screenies/Kamera.png)


### Menübar
Die intuitive Navigation der App.
* Schneller Zugriff auf alle Unterseiten (Gespeicherte Outfits, Galerie, Einstellungen etc).
* Responsives Design für verschidene Größen der Handys

![Alternativtext: Menübar](./screenies/Sidebar.png)

### Einstellungen
Einstellungen zur App und dem Konto.
* Schneller Zugriff auf Konto Einstellungen zum Verändern oder Löschen
* Designanpassungen (Dark / Lightmode) können hier getroffen werden.

![Alternativtext: Settings](./screenies/Maps.png)
